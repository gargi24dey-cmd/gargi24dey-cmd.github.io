Gender Patterns in India's Labour-Force Participation

A PLFS 2025 data preparation and analysis project

This project uses data from the Periodic Labour Force Survey (PLFS) 2025 to investigate gender-related patterns in India's labour-force participation. The current stage focuses on preparing and validating the PLFS dataset for further analysis of labour-force participation across demographic and geographic dimensions, using Python, Pandas, PySpark, and Google Colab.

Introduction

Labour-force participation is an important indicator of individuals' involvement in economic activity, and differences between men and women can vary across states and demographic or socioeconomic characteristics. The PLFS provides individual-level data — covering gender, age, education, state, rural-urban sector, marital status, social group, and principal activity status — that can be used to study these patterns. At this stage, the primary focus is ensuring the dataset is suitable for subsequent analysis through systematic examination and cleaning.

Data Loading

The raw PLFS dataset was loaded into the Google Colab environment via Google Drive, using a PySpark-based CSV loading process. The raw dataset was preserved separately throughout, so it would remain unmodified during preprocessing.

Data Quality Assessment

Before cleaning, the dataset was examined for its structure and potential quality issues, including row and column counts, missing values, duplicate records, blank/empty values, data types, categorical consistency, age values, sampling multiplier values, and potential outliers — providing a baseline for the cleaning process that followed.

Cleaning Approach

The process followed a conservative approach — identify, verify, and correct or remove only when justified — rather than applying automatic deletion or imputation:

  • Missing values: examined column-by-column; no unnecessary imputation or removal applied
  • Duplicate records: checked and genuine duplicates removed, with before/after counts compared
  • Blank strings: checked separately from standard null detection, since empty strings can hide as "non-missing"
  • Data types: reviewed for key variables; no artificial corrections were made where none were needed
  • Categorical consistency: variables like sex, state, sector, and activity status checked for inconsistent values, spelling differences, or extra spaces
  • Invalid values: age distribution investigated for impossible values (negative ages, ages above 120); none found requiring automatic deletion
  • Age outliers: identified using the IQR method and visually inspected via boxplot, but retained unless there was evidence they were erroneous — a statistically unusual age doesn't necessarily mean an incorrect one

Cleaned Dataset & Validation

A separate cleaned dataset was created and saved independently of the raw file, preserving the original for comparison. A before-and-after validation table was built comparing row counts, column counts, missing values, duplicates, invalid records, and data-type corrections — giving evidence that the cleaning was systematic rather than arbitrary. A cleaning log was also maintained, documenting each issue, observation, action taken, and justification, to keep the process transparent and reproducible.

Current Progress

The data preparation and cleaning stage is complete — from loading the raw dataset through structural inspection, missing-value and duplicate analysis, data-type and categorical checks, invalid-value and outlier investigation, to producing a validated, cleaned dataset with a full documentation log.

Project status: In Progress. The next stage will focus on Exploratory Data Analysis (EDA) of the cleaned PLFS dataset, examining patterns across gender, age, education, state, sector, and principal activity status.
